4 · What the layers prove — and what they don’t

Strong: module/subsystem correctness Independent Python oracles compare command, integral, trajectory, pulse phase, register state. Directed corners + seeded random inputs. Subsystem suite checks exact shared-engine lifecycle and cancellation.
Moderate: chip-level e2e 8 directed scenarios through real pins with a digital motor model. Endpoint/property assertions, not a full-system per-tick scoreboard. Module corner cases are not all repeated at top level.
Not covered yet No gate-level run of the full chip (1x1 hardening fails on area), no formal properties/equivalence, no functional coverage metric, no real motor/driver/board validation, no SPI majority voting or glitch filtering.

Status: counts reflect the Q16 shared-engine baseline, where module suites and the 8 integration tests pass. The checked-out tmp/q8-area-test branch is a temporary Q8 experiment that intentionally breaks low-acceleration profiles and fails its test run; it is not a valid baseline.
